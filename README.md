# 💍 Wedding Invitation Website

A modern, responsive wedding invitation website featuring RSVP functionality, Firebase integration, and a real-time admin dashboard.

---

## ✨ Features

### 🎨 Design & Experience
- Elegant glass door opening animation  
- Video background for immersive feel  
- Fully responsive (mobile & desktop optimized)  
- Smooth animations and transitions  

---

### 📩 Guest Interaction
- **RSVP System** with Firebase integration  
- **Ucapan (Wishes)** – real-time guest messages  
- **Countdown Timer** to wedding day  
- **Photo Gallery** – swipeable image carousel  

---

### ⚙️ Admin Features
- Admin dashboard for RSVP management  
- Real-time response tracking  
- Duplicate RSVP detection  
- Export guest data  

---

### 🌐 Additional Features
- Waze & Google Maps integration  
- Digital gift (QR code for bank transfer)  
- Live statistics display  

---

## 🛠️ Technologies Used

- **HTML5** – Semantic structure  
- **CSS3** – Custom styling & animations  
- **JavaScript** – Interactive functionality  
- **Firebase** – Database & real-time sync  
- **Google Fonts**:
  - Cinzel  
  - EB Garamond  
  - Cormorant Garamond  
  - Italianno
